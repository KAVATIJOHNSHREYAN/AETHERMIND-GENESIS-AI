## 🌟 Overview

**AetherMind Genesis** is an enterprise-grade, 100% Python autonomous AI System Architect. It dynamically parses raw user prompts into structured computational requirements and simulates a collaborative debate among **10 specialized AI Architect personas** to construct complete, multi-phase software engineering blueprints without relying on static text templates.

---

## ✨ Key Capabilities & Phases

- **🧠 Dynamic Computational Reasoning (`agents/parser.py`)**: Pure NLP prompt parsing that extracts primary entities, action verbs, target datastores, security compliance needs, and throughput targets without pre-baked static lists.
- **🗣️ 10 AI Architect Personas (`agents/engine.py`)**: Independent, role-specific reasoning generated by:
  1. 👑 **Lead Architect** (Strategy & Hexagonal / Microservice Patterns)
  2. 🛡️ **Security Architect** (Zero-Trust, mTLS, SAML, RBAC & HSM Encryption)
  3. ⚙️ **Backend Architect** (Async Runtimes: Rust/Axum, FastAPI, Golang Fiber)
  4. 🎨 **Frontend Architect** (Next.js 14, React 18, State Management)
  5. 🗄️ **Database Architect** (PostgreSQL 16, TimescaleDB, ScyllaDB NoSQL)
  6. ⚡ **Performance Engineer** (Cloudflare Edge Caching & Redis v7)
  7. 🚀 **DevOps Engineer** (Multi-Stage Docker, Kubernetes EKS/GKE, Helm)
  8. 💰 **Cost Optimization Agent** (Serverless vs Dedicated Cluster Budgeting)
  9. ⚓ **Reliability Engineer** (Multi-AZ Failover, RPO/RTO SLAs)
  10. 🧠 **Innovation Agent** (AI Streaming, Vector Search pgvector)
- **🗺️ Visual System Topology (Mermaid.js)**: Interactive C4 flowcharts and architectural component graphs.
- **🗄️ Relational DDL Schema Generator**: Auto-generates multi-table SQL DDL schemas and ER diagrams.
- **🔌 OpenAPI v3 Workbench**: Complete REST endpoint documentation covering GET, POST, PUT, DELETE methods with sample JSON payloads and error codes.
- **📊 Phase 8 Analytics Dashboard**: Real-time circular progress gauges, trend heatmaps, and a 6-axis Radar trade-off chart.
- **🚀 Phase 7 Deployment Hub**: Auto-synthesizes Dockerfile, Docker Compose, Nginx, Kubernetes, Terraform, and CI/CD GitHub Actions configs.
- **📥 Phase 9 Master Export Center**: Download complete 12-section software blueprints in Markdown (`.md`), DDL SQL (`.sql`), and spec files.
- **🖼️ High-Precision Design System**: Sleek glassmorphism theme with 3D logo branding and a translucent, animated neural-synapse background watermark.

## ⚡ Local Installation & Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/KAVATIJOHNSHREYAN/AETHERMIND-GENESIS-AI.git
cd AETHERMIND-GENESIS-AI
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
```bash
streamlit run app.py
```
Open your browser at `http://localhost:8501`.

## 🌐 Deploying to Vercel

AetherMind Genesis is configured out-of-the-box for seamless Vercel deployment:

### Deploy via Vercel CLI
```bash
npm i -g vercel
vercel
```

### Deploy via GitHub Integration
1. Push your repository to GitHub.
2. Import the project in your [Vercel Dashboard](https://vercel.com/new).
3. Vercel will automatically detect `vercel.json` and deploy using `@vercel/python`.

## 🧠 Multi-Objective Pareto Optimization

System performance is evaluated using a weighted multi-objective fitness function:

$$\text{Overall Score} = (S_{\text{security}} \cdot w_s) + (S_{\text{perf}} \cdot w_p) + (S_{\text{cost}} \cdot w_c) + (S_{\text{rel}} \cdot w_r)$$

Where weights $w_s, w_p, w_c, w_r$ are dynamically adjusted using sidebar Pareto sliders to simulate real-world system design trade-offs.
